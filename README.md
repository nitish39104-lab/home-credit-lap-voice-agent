# Home Credit LAP Qualification Voice Agent

## Project Overview
A voice agent built using Retell AI to conduct preliminary qualification for a Home Credit Loan Against Property (LAP).

## Objectives
- Collect basic customer and property details.
- Check preliminary qualification criteria.
- Identify the requested loan amount and preferred tenure.
- Route eligible enquiries to a loan specialist.
- Clearly communicate that final approval is subject to further verification.

## Qualification Flow
1. Greet the customer.
2. Confirm property type and document availability.
3. Check the requested loan amount against the configured limit of ₹75 lakh.
4. Ask about occupation and whether income is credited to a bank account.
5. Capture the preferred tenure (3–15 years).
6. Provide a preliminary outcome or route the customer to a specialist.

## Test Scenarios
- Residential property with original documents available.
- Agricultural property.
- Self-employed customer receiving income in cash.
- Requested loan amount above ₹75 lakh.
- Existing loan transfer or EMI-reduction enquiry.
- Customer requesting a callback.
- Original property documents unavailable.

## Tools Used
- Retell AI
- GitHub

## Disclaimer
This project demonstrates preliminary voice-based qualification. It does not guarantee loan eligibility, sanction, or disbursement. Final decisions require review by the lender.
